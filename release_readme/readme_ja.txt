◆ 各機能で使用する外部ツール
════════════════════════════════════════════════════════

VR動画ツールボックスは、複数の独立した小ツールの集合です。使用する機能に
よって必要な外部コンポーネントが異なります。

  - FFmpeg / ffprobe：動画・音声処理で共通して使う基本コンポーネントです。
  - Lada または Jasna：AIモザイク除去を使う場合のみ必要です。
  - 音声認識と IndexTTS-2.5 モデル：新しい文単位感情音声クローンで使用します。
    OmniVoice、ECAPA、pyannote は独立した従来版クローン機能だけで使用します。

┌─────────────────────────────────────────────────────┐
│  FFmpeg（動画・音声処理の基本コンポーネント）              │
└─────────────────────────────────────────────────────┘

1. 次のURLを開きます：https://www.gyan.dev/ffmpeg/builds/
2. 「ffmpeg-release-full.7z」（または .zip）を探してダウンロードします。
3. ダウンロード後に解凍し、解凍したフォルダ内の「bin」サブフォルダを開きます。
   中には ffmpeg.exe、ffprobe.exe などのファイルがあります。
4. ffmpeg.exe と ffprobe.exe を使えるようにする方法は、主に3つあります。
   方法1：この2つの .exe ファイルを VR_Video_Toolbox.exe と同じフォルダへコピーする
   方法2：この2つの .exe ファイルを C:\Windows または C:\Windows\System32 へコピーする
   方法3：解凍後、「bin」フォルダを Windows の PATH 環境変数に追加する

┌─────────────────────────────────────────────────────┐
│  Lada-CLI（AIモザイク除去モデル、NVIDIA GPU推奨）          │
└─────────────────────────────────────────────────────┘

1. 次のURLを開きます：https://codeberg.org/ladaapp/lada/releases
2. ページの案内に従って最新版をダウンロードします。
3. lada-cli.exe を使えるようにする方法は、主に2つあります。
   方法1：lada-cli フォルダ全体（_internal フォルダを含む）を本プログラムと同じ階層へコピーし、
          lada-cli.exe と VR_Video_Toolbox.exe が同じフォルダにある状態にする
   方法2：解凍後、lada-cli のフォルダを Windows の PATH に追加する
          例：D:\Lada\
4. 注意：Lada は NVIDIA GPU が必要です。GPU性能が高いほど処理は速くなります。
   CPU処理は非常に遅いため推奨しません。

┌─────────────────────────────────────────────────────┐
│  Jasna-CLI（AIモザイク除去の推奨代替）                    │
└─────────────────────────────────────────────────────┘

Jasna は Lada の新しい保守版ブランチで、機能は同等で、既存の処理フローと互換性があります。

1. 次のURLを開きます：https://github.com/Kruk2/jasna/releases
2. 最新の Windows 版をダウンロードして解凍します。
3. jasna.exe を使えるようにする方法は、主に2つあります。
   方法1：jasna フォルダ全体（_internal フォルダがある場合はそれも含む）を
          本プログラムと同じ階層へコピーする
   方法2：解凍後、Jasna のフォルダを Windows の PATH に追加する
          例：D:\Jasna\
4. メイン画面の「AIエンジン」で「Jasna」または「Lada」を選択できます。
   選択内容は自動的に保存されます。
5. 注意：Jasna も Lada と同様に NVIDIA GPU が必要です。


◆ モザイク除去ツール
════════════════════════════════════════════════════════

モザイク除去が必要な場合にだけ、この系統のツールを使用します。メイン画面には
複数のモザイク除去モードがあります。

┌─────────────────────────────────────────────────────┐
│  【推奨】ワンクリックモード                              │
└─────────────────────────────────────────────────────┘
  対応しやすいメーカー：S1VR、MDVR、VRKM、IPVR など、多くの主流メーカー。
  操作が最も簡単で、モザイク位置を自動判定して処理します。

  ▶ このモードが適しているか確認する方法
    VR機器で元動画を開き、画面下部のモザイク形状を確認します。
    モザイクが【扇形 / 弧状】に見える場合 → そのまま「ワンクリックモード」を使用します。
    モザイクが【正方形 / グリッド状】に見える場合 → 「先に魚眼視点へ変換」を有効にします。

┌─────────────────────────────────────────────────────┐
│  選択範囲 直接クロップモード                            │
└─────────────────────────────────────────────────────┘
  対象：通常の平面動画、または普通の画面で見たときにモザイクが矩形に見える動画。
  操作：モザイク範囲を手動で選択 → プログラムが処理し、元の位置へ重ね戻します。

┌─────────────────────────────────────────────────────┐
│  選択範囲 VR→平面モード                                │
└─────────────────────────────────────────────────────┘
  対象：FSVSS、SAVR、URVRSP、CRVR、PXVR など、および一部の 3DSVR 作品。

  ▶ このモードが適しているか確認する方法
    VR機器では画面下部のモザイクが【正方形】に見えるが、
    PCで元ファイルを見るとモザイクが【台形 / 斜め形状】に見える場合は、このモードを使用します。
  操作は少し複雑です。まずはワンクリックモードに慣れてから試すことを推奨します。

どのモードを使えばよいか分からない場合：
→ メイン画面の「モザイクの種類が不明なら 拡大ツールで確認」リンクを使って判断してください。


◆ 3つの「魚眼」オプションの意味
════════════════════════════════════════════════════════

本ソフトでは「魚眼」という言葉が3つの場所に出てきます。目的に合わせて選んでください。

1. ワンクリックモード：「先に魚眼視点へ変換」
   モザイク除去用の処理オプションです。VRゴーグル内でモザイクが
   正方形/グリッド状に見える場合、特に SAVR や URVRSP などの中央軸・
   画面下部のモザイクで試します。左右映像を一時的に魚眼の作業ビューへ
   変換し、処理後に元のVR投影へ戻します。最終出力は通常のVR動画です。

2. 分割 / 結合ツール：魚眼として分割、魚眼として結合
   手動ワークフロー向けです。魚眼分割は左右別々の魚眼ファイルを作ります。
   魚眼結合は、すでに復元済みの左右魚眼ファイルを半球VRへ戻してから
   SBS VR動画として結合します。

3. 投影変換ツール：半球 <-> 魚眼
   動画ファイルの投影形式を明示的に変えるためのツールです。魚眼ファイルを
   作りたい場合、または魚眼ファイルを半球VRへ戻したい場合に使います。
   左右が1本に入ったSBS動画では、dual-screen/SBS オプションを有効にして、
   左右を別々に変換してから正しく結合してください。

通常のモザイク除去では、まずワンクリックモードを使ってください。単独の
魚眼ファイルが必要な場合を除き、先に投影変換ツールを実行する必要はありません。


◆ 字幕一括生成ツール
════════════════════════════════════════════════════════

メイン画面の「日本語一括字幕ツール」から字幕生成機能を開けます。

この機能はモザイク除去とは独立しており、Lada は不要です。ただし、以下が必要です。
  1. FFmpeg（上記と同じ）
  2. 音声認識モデルファイル（初回使用時に「モデルをダウンロード」を押すと models フォルダへ保存されます）
  3. 【任意】NVIDIA GPU による高速化：
     CUDA 環境が検出されると自動的に有効になり、CPUより大幅に速くなります。
     NVIDIA GPU がない場合は CPU 認識に自動で切り替わります。速度は遅いですが使用できます。


◆ 文単位感情音声クローン
════════════════════════════════════════════════════════

メイン画面の「文単位感情音声クローン」を開きます。この新機能は Bilibili が
公開した最新のオープンソース IndexTTS-2.5 を使用します。各セリフの原音 WAV
を声質と感情の参照として直接使うため、参照テキスト、話者識別、話者分類、
SPEAKER 接頭辞は不要です。

音声クローン（単一動画）
   1. 「文字起こし・翻訳」を押して元動画を選びます。
   2. 翻訳文を確認して修正します。
   3. 「翻訳を校正してクローン音声ファイルを書き出し」を押して生成します。
   通常は各セリフに対応する原音 WAV を使います。短すぎる場合は、より長い
   原セリフを自動的に参照として選ぶため、基準音声を手動選択する必要はありません。

一括クローン
   「入力フォルダ」を選びます。「すべてのサブフォルダから動画ファイルを検索」
   は初期状態で有効です。現在のフォルダ内にある全動画の文字起こし、翻訳、
   文単位合成を完了してから次のフォルダへ進みます。「既存の中間ファイルと
   .SI.WAV をスキップ」を有効にすると、既存の audio16k.wav、manifest.json、
   source.srt、translated.srt、最終 .si.wav
   を再利用し、完了済みの段階を繰り返しません。

出力とミックス/吹き替え
   <動画名>.si.wav と <動画名>.si.duck.wav を生成します。「ミックス/吹き替え」
   は常に原音を残して下げ、初期値では最も強いダッキングを使い、クローン音声
   を重ねて _SI.mp4 を出力します。DLNA サーバーも同名の .SI.WAV をライブ
   ストリーム [SI] に直接ミックスできます。文ごとの参照音声と生成 WAV は
   元動画の隣の <動画名>.clone/indextts_v2_manifest/ に保持され、Windows の
   Temp ディレクトリには保存しません。

モデルは models/IndexTTS-2.5 に配置します。不足ファイルがある場合、プログラム
はこの固定ディレクトリへメイン/補助モデルを継続ダウンロードします（ModelScope
を優先し、失敗時は hf-mirror）。翻訳 API 設定は字幕翻訳と共通です。最終利用前に
翻訳文を確認し、生成した .si.wav または _SI.mp4 を試聴してください。

新機能と従来版の違い
   新しい「文単位感情音声クローン」：IndexTTS-2.5 を使用し、各セリフに対応
   する原音 WAV を参照します。参照テキストも話者識別も不要です。
   従来版「クローン翻訳吹き替え」：OmniVoice を使用し、話者識別と一致する
   参照テキストが必要です。簡単な音色設計にも対応します。両者はメイン画面上の
   独立した項目であり、別々のワークフローです。


◆ よくある質問
════════════════════════════════════════════════════════

Q: 「ffmpeg が見つかりません」と表示されます。
A: ffmpeg.exe が VR_Video_Toolbox.exe と同じフォルダにあるか確認してください。
   または、ffmpeg の bin フォルダを Windows の PATH 環境変数へ追加してください。

Q: モザイク除去の効果が弱い、または効果がありません。
A: Jasna と Lada は矩形モザイクに最も適しています。一部メーカーの特殊なモザイク形状は、
   AIで復元できない場合があります。これはモデル自体の技術的制限です。
   メイン画面の「AIエンジン」でエンジンを切り替えるか、別のモードを試してください。

Q: 字幕ツールの認識結果が文字化けする、または日本語ではありません。
A: このツールは標準で日本語音声を認識します。動画自体に日本語音声が含まれているか確認してください。
   認識結果は元動画と同じフォルダに .jp.srt 形式で保存されます。

Q: 実行中に "Option 'ad' not found" や "Error initializing filter" などのエラーが出ます。
A: ffmpeg のバージョンが古い、または必要な機能が省かれた軽量版を使っている可能性があります。
   本プログラムは高度な音声ノイズ低減や VR 全景フィルタを使用します。
   公式推奨ページから最新版の Full Build に置き換えてください。バージョン 6.0 以上を推奨します。
   ダウンロード先：https://www.gyan.dev/ffmpeg/builds/（ffmpeg-release-full.7z を選択）

Q: このプログラムの最新版はどこで入手できますか？
A: ホームページ：https://github.com/zerochocobo/VR-Video-Toolbox-CE
